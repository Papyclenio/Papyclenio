## 📂 Projecto em destaque

### [📘 IPAGE-Zone](https://github.com/Papyclenio/IPAGE-Zone_projetoParaFeira)

Plataforma web educacional desenvolvida para a Feira Tecnológica do IPAGE.

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Base de dados:** MySQL
- **Funcionalidades:** Cadastro de alunos, login com JWT, dashboard de progresso, exercícios por disciplina
